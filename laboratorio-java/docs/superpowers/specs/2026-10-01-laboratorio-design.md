# Laboratorio visual: diseño

Objetivo: resolver los materiales reales de Tema1 y Tema2 con Java y ventanas. No sustituir los enunciados por ejemplos genéricos. Preservar originales.

Java 17+, Swing/Java2D, sin dependencias externas. Motor puro sobre estados inmutables separado de la vista. SwingWorker para búsquedas con límites y cancelación; temporizadores detenidos al navegar.

Catálogo: robot reactivo, Grafo2, grafo de clase, DLS erróneo/correcto, A* Oradea, ping-pong, islas, misioneros, árbol, mala heurística, Column Jump y guía teórica. Datos editables, camino/traza, g/h/f, frontera y comparativa. Guía con formulaciones, correcciones y fuentes.

Aceptación: costes 16/23/429, DLS reabre a menor profundidad, árbol con órdenes exactos, islas 7 cruces/10 estados, misioneros 11 cruces/16 estados, Column Jump 8 saltos y secuencia del PDF. Ping-pong AB original imposible; BC como variante identificada. Capturas originales visibles sin simulador externo.

No se afirma equivalencia física de la nueva simulación con los AVI. No se inventan benchmarks de testExample1/2/3 ausentes. Presupuestos agotados no son pruebas de imposibilidad. Se conserva la meta cuando la traza se limita.
